# Expected values:
#   llm         normal conversation; no handler may claim it
#   tools       system/app/browser/music/maps handler
#   files       file or folder handler
#   calendar    calendar or reminders handler
#   screen      screen awareness
#   view        navigation to a UI destination (home / menu / a named panel)
#   market      stock quotes, indices, analyst ratings, company news
#   actuation   typing / clicking / keys / scrolling (work mode only)

#   fastpath    greeting / date / time / repeat
#   unsupported an action Nova cannot perform; must be refused, never faked
#   signoff     ends the conversation
#   no-signoff  mentions sleep words but is NOT a sign-off
